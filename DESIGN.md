# VibeDND — дизайн-документ (подтверждён)

Веб-приложение для живой игры в D&D 2024 (5.5e) в одном помещении.

## Три представления
- `/board` — общий экран (ТВ/проектор): интерактивная карта, токены, туман войны, трекер инициативы, лог бросков, QR-код сессии.
- `/dm` — консоль мастера (ноутбук): управление картой, токенами, туманом, инициативой, HP, библиотеки, редакторы.
- `/player/:characterId` — телефон игрока: карточка персонажа, трекинг ресурсов, виртуальные кости. Карту не показывает.

## Сеть и технологии
Локальный сервер на ноутбуке мастера; клиенты по Wi-Fi; вход по QR; без аккаунтов. Интерфейс на русском.
Стек: React + TypeScript + Vite · Node.js + Express + WebSocket (ws) · better-sqlite3. Автосохранение после каждого действия.

## Модель данных
- **Персонаж** — библиотека на сервере, хранится у мастера.
- **Приключение** — шаблон: карты (изображение + калибровка сетки), токены, сцены с заметками и артами.
- **Сессия** — экземпляр приключения + партия + живое состояние. Несколько параллельных сессий допустимы.

## Персонажи (D&D 2024)
Полное создание (1–12 ур.): вид, класс, предыстория, характеристики (standard array / point buy), заклинания, снаряжение; редактирование. Визард повышения уровня. Трекинг: HP + временные, кости хитов, ячейки, классовые ресурсы, состояния, концентрация (напоминание при уроне), настройка, спасброски от смерти. Короткий/длинный отдых. HP меняют игрок и мастер синхронно.

## Карта
Сетка 5 футов, калибровка поверх картинки. Токены: персонажи (отличаются), враги, НПС; двигает только мастер; полоска HP, состояния, «при смерти». Туман: прямоугольник + кисть, открыть/скрыть, «скрыть всё». Рисование: перо, линия, круг, прямоугольник, 5–6 цветов, ластик, очистка слоя. Измерение: круг-радиус.

## Бой
Трекер инициативы (ручной ввод или «кинуть всем», «следующий ход», счётчик раундов). Урон/лечение кликом в консоли. Кости: физические по умолчанию; виртуальные с авто-модификаторами, результат игроку + строка в лог на доске; скрытые броски мастера.

## Контент
Разовая заливка в базу (dnd.su, личное использование). Редакторы в MVP: монстр, заклинание, предмет. Классы/виды/предыстории — импорт JSON. Редактор приключений в MVP: карты + калибровка + токены + заметки/арты.

## Дизайн-ресурсы
Только открытые бесплатные источники: Google Fonts (Cinzel + Noto Sans), Lucide Icons (ISC), game-icons.net (CC-BY 3.0, плейсхолдеры токенов), чистые CSS-анимации (без библиотек).

## Вне MVP
Карта на телефоне, конус/линия измерений, парсер dnd.su, UI-редактор классов, автоматизация мастера, хостинг в интернете.
